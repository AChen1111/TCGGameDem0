# 中文 Git 协作规范

在此项目中创建或更新 Git 协作信息时，标题和说明必须使用中文。

- Git 提交主题和正文必须使用中文，保持简洁且准确描述改动。
- 新建分支名称、合并请求标题、Issue 标题和任务标题必须使用中文；需要技术标识时，可保留必要的英文专有名词、命令或代码符号。
- 不翻译代码、API 名称、文件路径、配置键、命令及业界固定术语；围绕它们的说明应使用中文。
- 提交前检查提交主题不含无意义的英文占位词，例如 `update`、`fix`、`wip`。
