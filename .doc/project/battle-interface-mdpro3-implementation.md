## 数据与点击流程

保留IDuelPresentationSource.Current/Changed/Submit。CardView.Actions给出动作标识/类型、表示及各表示对应目标；DuelView.PendingAction保存当前卡/动作/表示/步骤并参与输入锁。玩家资料和灵摆Flags从现有配置接入。

```csharp
// 流程示意：选目标前不移区。
source.Submit(new BeginCardAction(instanceId, actionId));
source.Submit(new ChooseActionPosition(position)); // 多表示时
source.Submit(new ConfirmActionTarget(zone)); // 此时才移区
source.Submit(new CancelCardAction()); // 保留原状态
```

1. 点击卡牌抬升选中，同步左详情和卡上方可用动作。
2. 通常召唤表攻，设置里守，特召多表示先选表示，Link仅攻；UI不自己推导合法性。
3. 动作确定后隐藏按钮，显示位置提示横条和黄色合法空位。
4. 点合法区域才提交并播放动画，非法点击不改变卡或数量。取消按钮、空白、Esc、安卓返回取消并清理提示。
5. 待操作和动画期间禁止另一移区/换卡/换阶段，计时和重置可用。鼠标悬停、触摸选中、单指捕获和UI遮挡保留，移动不进入拖牌。

演示动作覆盖手牌、场上、额外、墓地和除外，额外目标由演示配置明确提供。删除自动选择第一个空位捷径，调试入场也选目标。发动提交明确表现命令并播放反馈，不用开启高亮冒充发动，不结算真实卡效。
