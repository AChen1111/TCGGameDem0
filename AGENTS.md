# Project Skills

Project skills have a single shared source under `.skills/`.

Before doing any work, read `.skills/project-development/SKILL.md` completely and follow it.

Before work that matches a skill, read its `SKILL.md` completely and follow it:

- Unity Editor, scene, GameObject, compilation, testing, screenshot, or Unity Pipeline work: `.skills/unity-pipeline/SKILL.md`
- Git commit, branch, merge request, issue, or task naming: `.skills/chinese-git-conventions/SKILL.md`

Do not look for duplicated project skills under tool-specific directories.
